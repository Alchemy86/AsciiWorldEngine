ASCIIWORLDENGINE

The city, the camera, the projection, every glyph and every colour are decided in Rust; this page loads the module, feeds keys and a dt in, and paints the bytes that come back.

The native terminal binary is the real front end - cargo run --release. This page is the optional extra target.
